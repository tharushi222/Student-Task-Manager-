# Student Task Manager 📚

A simple and user-friendly Student Task Manager website designed to help students organize and manage their academic tasks efficiently.

## 🚀 Features

- **Add Tasks** – Add new tasks with a title, subject, due date, and priority.
- **Edit Tasks** – Update task details when needed.
- **Complete Tasks** – Mark tasks as completed or undo completion.
- **Delete Tasks** – Remove tasks that are no longer needed.
- **Search Tasks** – Search tasks by title or subject.
- **Dashboard** – View the total, pending, and completed task counts.
- **Local Storage** – Save tasks in the browser so they remain available after refreshing the page.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 💻 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Start adding and managing your tasks!
